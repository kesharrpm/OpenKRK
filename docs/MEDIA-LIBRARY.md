# Media library behavior

OpenKRK supports a single mixed media root. MID, MIDI, KAR and supported BGV video files may live in the same folder tree; F2 scans and classifies both types in one pass. F3 remains an optional visual-only override.

Songs whose filenames do not contain a numeric song number receive a stable OpenKRK local number in the 9000000–9999999 range. The local number is cached and can be searched or typed through direct entry just like a source song number. OpenKRK does not rename or modify the user's media files.
